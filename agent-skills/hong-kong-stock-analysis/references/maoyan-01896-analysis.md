## 竞争分析: 抖音入局票务的三步走

### 抖音票务策略演进
| 阶段 | 时间 | 行为 | 对猫眼影响 |
|------|------|------|-----------|
| **Phase 1 — 宣发导流** | 2021-2023 | 抖音成为电影最大宣发阵地; 预告片、花絮、达人解说 | 无直接影响(猫眼仍然卖票) |
| **Phase 2 — 直播卖票** | 2023-2024 | 抖音开放直播间卖电影票; 达人/主播可以带票; 发起"达人票补"价格战 | 开始抢夺增量票房, 但主流用户仍用猫眼 |
| **Phase 3 — 全面入局** | 2025-2026 | 完善票务体验(选座、退改签、会员体系); 市占率从<5%提升至~15-20% | 结构性威胁形成 |

### 市场份额估计 (2026年6月)
| 平台 | 市场份额 | 趋势 |
|------|---------|------|
| 猫眼 | ~55-60% | 缓慢下降 |
| 淘票票 | ~20-25% | 稳定 |
| 抖音电影票 | ~15-20% | 快速上升 |
| 其他 | ~5% | — |

### 抖音的软肋
- 电影票是低利润生意(毛利率~5-8%), 抖音习惯了高毛利(广告、电商抽佣), 长期能否坚持亏损运营是未知数
- 猫眼有完整的行业数据服务(实时票房/排片/预测) — 是行业基础设施, 抖音短期无法替代
- 与院线的系统对接深度不如猫眼

## 三条命分析框架应用

```
第一条命(已死): 纯在线票务平台
  → 增长见顶, 被抖音分食
  → 越来越弱的生意, 利润极薄, 门槛低
  → 这是市场定价的核心叙事

第二条命(活着的): 电影全产业链服务
  → 宣发、数据、内容出品
  → 2025年净利5.64亿(+210%)证明走得通
  → 但营收增速仅13.5%, 算不上高增长

第三条命(孕育中): 泛娱乐消费平台
  → 演出、展览、体育赛事、IP衍生品
  → 目前规模小, 但方向对
  → 需要时间验证能否撑起估值
```

## 抖音 vs 视频号: 竞争研判

| 维度 | 抖音 | 视频号 |
|------|------|--------|
| DAU | ~7-8亿(已见顶) | ~5-6亿(仍在增长) |
| 用户时长/天 | ~120分钟 | ~50-60分钟 |
| 电商GMV | ~2万亿 | ~数千亿 |
| 商业化成熟度 | 极高 | 中 |
| 长期潜力 | 短期仍最强, DAU见顶 | 长期潜力更大(12亿微信MAU底座), 正在蚕食抖音时长 |

视频号是抖音目前最真实的威胁 — 微信的社交关系链+12亿MAU是字节无法复制的。

## 投资决策应用

### 结构性vs周期性分析
猫眼面临 **两者兼有**:
- **结构性威胁**: 抖音正在改变用户购票入口, 猫眼从"看电影的起点"降级为"购票工具", 这是不可逆的
- **周期性压力**: 2026年春节档票房同比-40%, 行业整体低迷, 这是可逆的

### 最坏情况估值(拍脑袋)
```
正常化盈利假设: 3-4亿(行业低迷年份)
给予保守PE: 8x (港股价值股)
最坏市值: 24-32亿HKD
对应股价: 2.8-3.7 HKD
当前价距最坏情形: 30-45%下行空间
```

### 关键催化剂
- 2026暑期档(7-8月) — 若有爆款, 短期反弹至6-7
- 2026中报(8月) — 验证转型是否持续, 营收增速是否维持
- 分红政策变化 — 股息增加是管理层信心的信号

- 但PB=0.6提供一定安全垫 — 可作为反向仓位持有, 不宜重仓
