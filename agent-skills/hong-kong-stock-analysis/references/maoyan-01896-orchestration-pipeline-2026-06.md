## 管线产出

### 子代理任务规格

**Industry Agent** context 要点:
- 公司名称、代码、当前价
- 业务结构、关键财务数据(2025年营收46.3亿/利润5.64亿/ROE 6.15%)

- 语言: 中文

**Bull-Bear Agent** context 要点:
- 发放完整5年财务表格(2021-2025)
- 突出关键异常: 净利率波动(YoY: +765%→-80%→+210%), 毛利率趋势性下滑(62%→43%)
- 要求: 看多和看空各4-5个论点, 每个都要数据支撑; 输出conflict map

**Technical Agent** context 要点:
- 价格数据、均线排列(MA5<MA10<MA20<MA60<MA120完全空头)
- 年度表现表、52周范围、ATH数据
- 要求: 均线/支撑阻力/RSI布林带/成交量/形态/时间节点(除净日6/25)

## 关键编号技巧

1. akshare的`stock_hk_financial_indicator_em`返回的ROE单位是%, 但ROE_AVG字段可能在不同函数中有不同scale——注意检查
2. `date`列永远是datetime64类型, 用`.dt.year`过滤, 不能用`.str.contains()`
3. Sina实时行情返回GBK编码, 必须`iconv -f gbk -t utf-8`解码或添加`Referer`头, 否则中文乱码
4. Sina的52周高低点字段在第14-15位(0-indexed: 14,15), 分别是`8.650`和`5.170`
5. 港股PE和A股PE不可直接比较——港股PE通常低30-50%
