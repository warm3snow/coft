- **价格**：5291 元/吨（6月-2.36%）
- **市场结构**：Contango（远月升水276点）
- **技术面**：MA5=5317 < MA10=5369 < MA20=5380，空头排列

- **短期逻辑**：巴西增产压制 → 下跌提供中长期建仓机会

- **价格**：2939 元/吨（6月-1.87%）
- **技术面**：MA5=2915 < MA10=2945 < MA20=2968

- **厄尔尼诺影响**：短期偏空（美豆产区降雨利好），中长期偏多（南美干旱预期）

- **当前主要驱动**：中东地缘 > 加息预期 > 厄尔尼诺
