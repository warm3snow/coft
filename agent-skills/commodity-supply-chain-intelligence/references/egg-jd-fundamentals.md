# 鸡蛋（JD）期货基本面知识库

## 品种概况

- **代码**: JD | **交易所**: DCE（大连商品交易所）
- **交割方式**: 现金交割（无仓库仓单，仓单数据对JD不适用）
- **合约单位**: 5吨/手 | **报价单位**: 元/500千克
- **交易时间**: 09:00-10:15, 10:30-11:30, 13:30-15:00

## 供应端核心驱动

### 在产蛋鸡存栏量（最核心指标）

鸡蛋的供应主要由在产蛋鸡存栏量决定。数据来源：Mysteel/卓创资讯每月发布的存栏报告。

```
补栏 → 育雏(4个月) → 开产(120天) → 产蛋高峰(持续约6个月) → 逐步淘汰(一般500天)
```

**关键推导关系**：
- 鸡苗补栏量 → 4个月后 → 新开产蛋鸡数量
- 当前在产存栏 = 前4-20个月补栏量之和 - 已淘汰量
- 补栏断档导致4个月后供应收缩，是价格拐点的前兆信号

**常用前置指标**：
- 鸡苗价格/销量：反映养殖户补栏积极性，领先在产存栏约4个月
- 淘汰鸡价格/日龄：淘汰价格高→提前淘汰（供应收缩），淘汰价格低→延后淘汰（供应增加）
- 蛋料比（鸡蛋价格/饲料成本）：高于盈亏平衡线→补栏意愿强，低于→加速淘汰

### 饲料成本（成本端）

蛋鸡饲料配方约60%玉米 + 25%豆粕 + 其他。玉米和豆粕期货价格直接影响养殖利润。

**蛋料比估算公式**:
```
每斤饲料成本 = (玉米价×0.6 + 豆粕价×0.25) ÷ 1000 × 2.2
（每产1斤鸡蛋约需2.2斤饲料）
```

正常养殖成本约 2.8-3.2 元/斤（2025-2026年），当蛋价超过4.5元/斤时利润显著。

### 季节性淘汰节奏

- 春节后：传统补栏旺季，养殖户集中补栏
- 梅雨季（6-7月）：高温高湿，产蛋率下降2-5%；鸡蛋保质期短，贸易商加速出货
- 中秋节前：食品厂备货推动需求高峰，节前1-2月蛋价季节性上涨
- 冬季：产蛋率因低温略降

## 需求端特征

### 季节性消费

| 时期 | 需求特征 |
|------|---------|
| 春节前（1-2月） | 年货采购高峰，需求最旺盛 |
| 春节后（3-4月） | 传统淡季 |
| 端午节前（5-6月） | 粽子用蛋+日常消费，年内第二个小高峰 |
| 夏季（7-8月） | 气温高，保质期短，贸易商快进快出 |
| 中秋节前（9月） | 月饼/糕点用蛋，需求旺季 |
| 国庆后-年底 | 需求平稳 |

### 需求替代关系

- 猪肉价格高→部分蛋白需求转向鸡蛋（需求增加）
- 蔬菜价格高→鸡蛋作为相对便宜的蛋白来源需求增加
- 学校开学/工地复工→团体食堂需求恢复

## 典型价差结构

鸡蛋期货合约呈现明显的季节性：

```
JD2607(7月)  4254 ← 近月反映当前现货
                  ↘ +455 (+10.7%)
JD2608(8月)  4709 ← 夏末旺季峰值
                  ↙ -251 (-5.3%)
JD2609(9月)  4458 ← 旺季尾声
                  ↙ -197 (-4.4%)
JD2610(10月) 4261 ← 节后淡季
                  ↙
JD2701(1月)  3865 ← 新补栏产能释放预期
                  ↙
JD2702(2月)  3409 ← 节后淡季+产能恢复
```

**规律**：
- 8月合约一般是年内的价格峰值（季节+资金博弈焦点）
- 1月后的远月合约价格大幅低于近月（Backwardation），反映的是补栏后供应恢复的预期
- 如果Backwardation收窄（远月价格相对上升），说明市场认为供应恢复会推迟
