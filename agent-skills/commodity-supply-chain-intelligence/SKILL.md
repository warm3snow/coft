# 大宗商品供应链与地缘政治分析

当用户询问某个大宗商品期货时，使用此技能获取最新全球供应链全景、地缘政治影响、供求库存数据、价格行情和操作建议。

## 核心工作流

### Step 1: 确定商品与查询参数

从用户消息中提取：
- **商品名称（中文）** — 如"甲醇"、"PTA"、"红枣"
- **期货品种代码** — 如 MA（甲醇）、TA（PTA）、CJ（红枣）
- **交易所** — CZCE/郑商所、DCE/大商所、SHFE/上期所、GFEX/广期所
- **主力合约** — 如 MA2609、TA2609

如果用户只给了商品名没给代码，先查询合约信息确定代码。

### Step 2: 运行综合分析脚本

```bash
python3 ~/.hermes/skills/data-science/commodity-supply-chain-intelligence/scripts/commodity_intel.py "<商品名>" "<品种代码>"
# 示例:
#   commodity_intel.py "红枣" "CJ"
#   commodity_intel.py "生猪" "LH"
#   commodity_intel.py "甲醇" "MA"
#   commodity_intel.py "螺纹钢" "RB"
#   commodity_intel.py "PTA" "TA"  (可选第三个参数指定主力合约)
```

该脚本通过 akshare 获取以下 10 个维度的结构化数据：

| 阶段 | 内容 | 数据来源 |
|------|------|---------|
| 📈 第一阶段 | **各合约报价详情** — 5-6个主要合约的Open/High/Low/Close/Vol/持仓/涨跌幅；判定Backwardation/Contango | akshare 逐个合约查询 |
| 📊 第二阶段 | **月度与年度走势概览** — 本月内表现、产季分析（10月-次年9月）、季度/月度分段涨跌、历史同期季节性 | akshare 主力连续 |
| 📉 第三阶段 | **近期每日行情细节** — 近15日OHLCV+持仓+量比 | akshare 主力连续 |
| 📉 第四阶段 | **技术面分析** — MA5/10/20、量价关系解读、持仓趋势、支撑阻力 | pandas 计算 |
| 🏭 第五阶段 | **仓单数据** — 交易所注册仓单（现金交割品种自动提示） | akshare 仓单API |
| 🌍 第六阶段 | **全球供应链地图** — 生产国/消费国/贸易流（web_search，可能被拦截） | 可选web搜索 |
| 🌐 第七阶段 | **地缘政治影响** — 制裁/关税/出口限制（web_search，可能被拦截） | 可选web搜索 |
| 📋 第八阶段 | **全球供求与库存** — 供需平衡表（web_search，可能被拦截） | 可选web搜索 |
| 💰 第九阶段 | **现货与国际价格** | 可选web搜索 |
| 💵 第十阶段 | **国际市场价格** | 可选web搜索 |

> ⚠️ 第6-10阶段的web搜索依赖DuckDuckGo的curl访问，部分环境可能被拦截（显示"搜索引擎验证拦截"），此时由你（agent）自行用 web_search 工具补充搜索即可。

### Step 3: Agent 自行补充搜索（如脚本已拦截）

## 果树品种专题：大年/小年分析框架

当用户询问水果类品种（红枣、苹果等）的产量年景时，使用以下分析框架：

### 什么是"大年/小年"

果树存在**自然大小年结果（biennial bearing）** 现象：大年（丰产年）树体营养消耗大，花芽分化差，次年转为小年（减产年）；反之亦然。

### 多维度判断框架

| 维度 | 判断资料 |
|------|---------|
| 花期/坐果情况 | 搜索产区新闻报道（如"盛花期"、"坐果率"、"保花保果"） |
| 天气风险 | 坐果期高温干热风/低温阴雨/冰雹等极端天气报道 |
| 上年产量基数和价格 | 上年是大年还是小年？价格高位→通常上期产量偏低 |
| 价格结构 | Contango→供应宽松预期（倾向于大年）；Backwardation→供应紧张（倾向于小年） |
| 种植面积变化 | 是否有退林还耕、枣园改种等政策影响 |
| 关键技术节点 | **5-6月盛花期**→**6-7月坐果期**→**7-8月果实膨大期**→**9-10月成熟采收期** |

### 搜索策略

```
# 花期坐果报道（5-7月）
browser_navigate("https://search.sina.com.cn/search?q=红枣+盛花期+坐果+新疆&tp=news&sort=time")

# 天气影响（全年）
browser_navigate("https://search.sina.com.cn/search?q=红枣+天气+减产+新疆&tp=news&sort=time")

# 产量预估（8-10月）
browser_navigate("https://search.sina.com.cn/search?q=红枣+产量+新疆+预估+2026&tp=news&sort=time")
```

红枣物候期（以新疆为例）：
- 4月中旬：萌芽展叶期
- 5月下旬-6月：盛花期（最关键的产量决定窗口）
- 6-7月：坐果期（高温干热风是最大威胁）
- 8-9月：果实膨大期
- 10月-11月：成熟采收期

### 🔥 进阶：天气/气候数据集成框架

当分析果树类品种（红枣、苹果等）或任何天气敏感型商品时，在基础的大年/小年判断外，主动补充**天气气候维度**的数据采集和情景推演：

#### 搜索实时产区天气预警

新浪搜索可直接获取各地气象台发布的预警信号，无需访问气象局官网：

```
# 搜索产区天气预警
browser_navigate("https://search.sina.com.cn/search?q={产区名}+气象台+发布+高温+预警+信号&tp=news&sort=time")
```

**实际案例（2026年6月红枣）**：
- 搜索 `阿克苏 气象台 高温 预警 信号` → 获得阿克苏多县橙色高温预警（6月1-4日，37℃+）
- 找到的关键实况：拜城、库车、新和、柯坪等**红枣主产县**全部发布高温橙色预警
- 将此与红枣物候期（盛花期→坐果期转接）对应，判断天气风险概率

**预警信号含义**：
| 预警等级 | 含义 | 对果树影响 |
|---------|------|-----------|
| 黄色 | 连续3天≥35℃ | 轻度胁迫，关注 |
| **橙色** | **24小时内≥37℃** | **中度胁迫，坐果期需警惕** |
| 红色 | 24小时内≥40℃ | 严重胁迫，大概率减产 |

#### 搜索历史气候趋势数据

通过新浪搜索获取气候变化科学报告，评估产区极端天气概率是否在上升：

```
# 搜索产区气候变化趋势
browser_navigate("https://search.sina.com.cn/search?q={产区所在省份}+气候变化+升温+速率+高温日数+趋势&tp=news&sort=time")
```

**实际案例（新疆红枣）**：
- 搜索 `新疆 气候变化 蓝皮书 升温 高温日数` 可获得：
  - 《中国气候变化蓝皮书》数据（中国升温速率0.26℃/10年，高于全球）
  - 新疆气象局发布报告（冬季创1961年以来最高+2.5℃）
  - 产区90年代至今升温趋势（阿尔金山30年+1.5℃）
  - 国家气候中心常年预报（新疆夏季高温日数偏多）
- 这些数据帮助判断：**极端天气已不是偶发，而是趋势性上升**

#### 搜索现货市场数据

新浪财经上常有贸易商/资讯公司发布每日现货数据汇总：

```
# 搜索现货报价
browser_navigate("https://search.sina.com.cn/search?q={商品名}+现货+数据+汇总&tp=news&sort=time")
```

**实际案例**：
- 搜索 `红枣 现货 数据 汇总` → 找到**弘毅物产**每日发布红枣现货数据
- 获取信息：崔尔庄市场到货4车（120吨）、广州如意坊到货2车
- 现货走货量是验证期货价格基本面的关键高频数据

#### 天气情景 → 期货定位框架

将收集到的气候/天气/现货数据整合为**情景矩阵**，用于判断多空方向：

```\n┌─────────────────────────────────────────────────────┐\n│  天气情景           │  坐果影响  │  期货预期  │  分析推断 │\n├─────────────────────────────────────────────────────┤\n│ 花期正常 + 坐果期    │  丰产      │  Contango  │  远月承压 │\n│ 温和                │            │  压力持续  │           │\n├─────────────────────────────────────────────────────┤\n│ 花期正常 + 坐果期    │  减产      │  供应收紧  │  近月偏强 │\n│ 高温干热风>7天       │            │  Backwardn │           │\n├─────────────────────────────────────────────────────┤\n│ 历史升温趋势显著      │  极端天气  │  天气炒作  │  波动加剧 │\n│ + 当前已现高温预警     │  概率↑     │  窗口     │           │\n└─────────────────────────────────────────────────────┘
```

**核心原则**：
- Contango结构（远月升水）是天气驱动行情的天然土壤——只要有减产消息，就能引发剧烈反弹
- 2025年7月红枣大涨+24%就是典型：Contango结构 + 坐果期不利天气 = 天气炒作行情
- 当前（6月）的高温预警不等于7月坐果期一定出问题，但**升温趋势使概率逐年上升**

## 🌍 宏观气候事件专题：ENSO/厄尔尼诺/拉尼娜跨品种分析

当用户问及**宏观气候事件（厄尔尼诺/拉尼娜/ENSO）对大宗商品的整体影响**时，使用本节框架进行跨品种的横向分析。这与Step 2的单一品种脚本不同——此处需要**同时评估多个商品的反应层级、传导路径和时间差**。

### 第一步：确认ENSO事件状态

| 查询来源 | 搜索词 | 说明 |
|---------|--------|------|
| 新浪新闻（中文可靠） | `美国宣布 厄尔尼诺 形成 2026` | 中文媒体转载NOAA官方公告 |
| 新浪新闻 | `厄尔尼诺 大宗商品 影响 期货 2026` | 券商/期货公司研报解读 |
| 新浪新闻 | `强厄尔尼诺 将贯穿 2026下半年 哪些行业` | 行业影响分析 |

关键参数确认：
- **形成时间**（是刚宣布形成还是已持续数月？）
- **预测强度**（弱/中等/强/超强？）
- **持续时间**（持续到年底/跨年/更久？）
- 区分 **"形成预期炒作"** 与 **"强度定价确认"** 两个阶段（价格行为完全不同）

### 第二步：按敏感度层级分类商品

厄尔尼诺对商品的影响按**敏感度从高到低**分三层：

| 层级 | 敏感度 | 品种 | 核心传导链 |
|------|--------|------|-----------|
| 🔴 **第1层（高敏感）** | 最直接、最强、有历史规律可循 | 白糖(SR)、棕榈油→豆油(Y)/菜油(OI)、天然橡胶(RU/NR) | 海温异常→季风减弱→降雨减少→作物减产→供应收缩→价格上涨 |
| 🟡 **第2层（中敏感）** | 影响存在但方向复杂或滞后较长 | 豆粕(M)、棉花(CF)、铜(CU)、其他农产品 | 影响路径有区域差异或受其他因素对冲 |
| ⚪ **第3层（低敏感/间接）** | 宏观情绪传导而非基本面的直接影响 | 原油(SC)、黑色系(RB/I/JM) | 通过通胀预期、汇率、替代品等间接传导 |

### 第三步：评估各品种的传导路径与滞后期

#### 🔴 第1层（高敏感品种）

**白糖（SR）** — 影响确定性最高
```
厄尔尼诺 → 印度季风减弱/泰国干旱 → 甘蔗缺水 → 种植面积/单产双降 → 全球供需由过剩转短缺 → 糖价上涨
```
- 滞后期：**6-12个月**（当前季风期决定下个榨季产量）
- 历史验证：2000年以来多次厄尔尼诺均对糖价产生正面影响
- 关键时间窗口：6-7月印度季风期、9-10月新榨季开启
- 注意：巴西中南部增产（厄尔尼诺带来更多降雨）可能部分对冲
- Contango结构下，远月合约（SR2701）比近月（SR2609）更能反映减产预期

**棕榈油 → 豆油(Y)/菜油(OI)**
```
厄尔尼诺 → 东南亚干旱 → 棕榈果单产下降（6-9个月滞后期）→ 全球油脂供应收紧 → 价格上涨
```
- 历史参考：2015-2016年强厄尔尼诺导致棕榈油减产20%+，价格上涨超50%
- 叠加因素：印尼B50生物柴油政策放大需求
- 菜油额外受加拿大/欧盟/澳大利亚油料产区天气影响

**天然橡胶（RU/NR）**
```
厄尔尼诺 → 东南亚干旱 → 割胶天数减少、胶水干含降低 → 产量下降
```
- 滞后期：**3-6个月**（胶树对干旱反应较快）
- 产区原料价格上涨是先行指标

#### 🟡 第2层（中敏感品种）

**豆粕（M）**
```
厄尔尼诺 → ① 美国中西部降雨增加（利多美豆产量，短期偏空）
             ② 南美（阿根廷/巴西南部）干旱（利空南美产量，中长期偏多）
```
- 北半球生长季（4-9月）：厄尔尼诺给美国中西部带来更多降雨 → **增产效应**（短期利空）
- 南半球种植季（10-3月）：厄尔尼诺导致阿根廷/巴西南部干旱 → **减产效应**（中长期利多）
- 策略：买M2701抛M2609做远月升水

**棉花（CF）**
```
厄尔尼诺 → 影响高度分化：澳洲干旱、中国新疆多雨、美国不确定
```
- 整体影响偏负面但不如白糖/橡胶清晰
- 当前受巨量仓单和下游弱势压制

**铜（CU）**
```
厄尔尼诺 → 智利/秘鲁暴雨 → 铜矿减产/运输中断
```
- 影响需强厄尔尼诺才显著
- 当前受宏观（加息）+地缘（中东）压制更重，厄尔尼诺故事需Q3-Q4兑现

#### ⚪ 第3层（低敏感品种）
- **原油(SC)**：厄尔尼诺减少大西洋飓风（偏利好），但中东地缘才是核心驱动
- **黑色系(RB/I/JM)**：厄尔尼诺几乎不直接影响

### 第四步：情景矩阵与阶段判断

当前厄尔尼诺所处的**阶段**决定了价格行为的模式：

| 阶段 | 时间窗口 | 价格行为特征 | 分析要点 |\n|------|---------|------------|---------|\n| 形成初期 | 宣布后1-2月 | 预期炒作→快涨快跌，持仓增但价格反复 | 远月合约开始反映预期，近月受现实压制 |\n| 强度确认期 | 形成后2-4月 | 高频气象数据（降雨量/干旱指数）驱动日级别波动 | 跟踪数据确认/证伪预期 |\n| 影响兑现期 | 形成后4-6月+ | 减产数据公布→主升浪，Backwardation可能形成 | 关注供需数据发布节点 |

### 第五步：跨品种分析要点框架

**核心要点：**
1. **强厄尔尼诺 + Contango结构 = 天气预期交易的天然土壤**\n2. **关注远月 vs 近月的价差变化** — 近月受现实供应压制，远月反映减产预期，价差是核心观测变量\n3. **优先分析确定性最高的品种** — 白糖（历史验证最可靠）> 棕榈油/油脂 > 橡胶 > 其他\n4. **注意地缘冲突叠加** — 中东冲突（如霍尔木兹海峡关闭）会放大整体波动\n5. **跨期价差分析优于方向分析** — 买远抛近的跨期价差分析在Contango结构下的信噪比更高

## 脚本说明

配套脚本 `scripts/commodity_intel.py` 负责数据采集，使用以下数据源：

- **akshare** — 国内期货价格、仓单
- **web_search** (从脚本内通过 curl + jq 调用搜索 API) — 全球供应链、地缘新闻
- 未来可扩展: EIA/OPEC/ICIS 等专业数据源

## 注意事项

1. **数据时效性** — akshare 数据可能有 15 分钟延迟；日线数据在闭市后 ~18:00 CST 可用
2. **脚本依赖** — 需要 `akshare`, `pandas`；如未安装自动尝试安装
3. **品种覆盖** — 该脚本覆盖国内期货交易所主要品种；国际品种（LME/CME）需补充搜索
4. **合约结构回退** — `futures_zh_realtime()` 有时返回空（列名/代码不匹配），脚本会自动降级为逐个合约通过 `futures_zh_daily_sina` 查询
5. **`futures_main_sina` 特定品种失败** — 部分DCE品种（如JD鸡蛋）的 `futures_main_sina` 调用返回 JSON 解析错误（"Expected object or value"）。脚本的逐个合约回退机制（`futures_zh_daily_sina`）能自动绕过此问题，不影响分析质量。其他DCE品种遇到类似情况同理处理。
6. **搜索引擎拦截与替代方案** — 百度/Bing/Google/DDG 均可能触发验证码。**新浪搜索（search.sina.com.cn）无需验证码**，作为中文商品新闻的首选搜索入口。用法：`browser_navigate(url="https://search.sina.com.cn/search?q={关键词}&tp=news&sort=time")`。当所有搜索都被拦时，依靠 akshare + 品种常识 + Sina新闻搜索完成分析。
7. **execute_code 引号陷阱** — 不要在 `execute_code` 的 code 参数内嵌套 `terminal("python3 -c \\\"...\\\"")`，多层引号会解析失败。改为写临时文件 `/tmp/foo.py` + `terminal("python3 /tmp/foo.py")`
8. **参考文件** — `references/hongzao-cj-analysis-20260609.md` 包含一次完整分析全过程的记录，是最终报告格式的模板。`references/methanol-ma-fundamentals.md` 包含甲醇基本面知识库（供应链地图、驱动因素、季节性规律等），当搜索被拦截时可快速查阅。`references/egg-jd-fundamentals.md` 包含鸡蛋期货基本面知识库（存栏推导、饲料成本计算、季节性价差规律等）。`references/sina-search-workaround.md` 包含新浪搜索的详细使用指南（中文商品新闻搜索不触发验证码的可靠入口）。`references/xinjiang-climate-trends-2000-2025.md` 包含新疆2000-2025年气温历史数据，用于红枣等新疆农产品分析的气候背景参考。
