# Backtrader 趋势跟踪策略 Demo

SMA 双均线 + ADX 趋势过滤 + ATR 移动止盈止损。东方财富数据 + Backtrader 回测。

## 策略说明

### TrendFollowing：趋势跟踪 + 移动止盈止损

| 组件 | 说明 |
|------|------|
| 入场信号 | SMA20 上穿 SMA60（金叉）**且 ADX > 18**（确认趋势存在） |
| 出场信号 | SMA 死叉 或 价格跌破移动止损线 |
| 移动止损 | 初始 = 入场价 - 2.5×ATR；持仓期间 `max(当前止损, close - mult×ATR)`，只升不降 |
| 移动止盈 | 浮盈 > 3×ATR 时，止损倍数从 2.5 收紧为 1.2，加速锁利 |
| 仓位管理 | 单笔风险 = 账户 × 5%，最大仓位 90% |
| ADX 过滤 | ADX(14) < 18 时不入场，避免震荡市假信号 |

### 对照基准

- Buy & Hold：满仓持有同标的

## 回测配置

- 标的：沪深 300 ETF（510300）、贵州茅台（600519）
- 数据：后复权日线
- 区间：2012-12 ~ 2025-12
- 初始资金：¥100,000（ETF）/ ¥500,000（茅台）
- 手续费：万 2.5（单边）；茅台额外含千 1 印花税
- 滑点：5 bp
- 撮合：下一根 bar 开盘价成交（Backtrader 默认）

## 快速开始

```bash
pip install -r requirements.txt
python main.py
```

首次运行从东方财富 API 拉取数据并缓存为 CSV。后续直接读取缓存，删除 CSV 可刷新。

## 输出

运行后打印策略评估指标，并生成对比图：

- `trend_csi300.png` — 沪深300 ETF 净值 + 回撤对比
- `trend_moutai.png` — 贵州茅台净值 + 回撤对比

示例结果：

| 标的 | 策略 | 年化收益 | 最大回撤 | 夏普比率 | 交易次数 | 胜率 |
|------|------|----------|----------|----------|----------|------|
| 沪深300 | Buy & Hold | 7.51% | 43.44% | 0.023 | — | — |
| 沪深300 | TrendFollowing | 0.17% | 12.86% | -0.025 | 17 | 47.1% |
| 茅台 | Buy & Hold | 19.21% | 44.96% | 0.045 | — | — |
| 茅台 | TrendFollowing | 2.66% | 16.57% | 0.008 | 19 | 57.9% |

**核心特征**：趋势策略用收益换回撤——最大回撤从 43~45% 压到 12~17%，适合风险厌恶型投资者。

## 涵盖的量化核心概念

1. **事件驱动** — `next()` 每根 K 线触发一次
2. **未来函数** — 信号基于历史计算，下一根 bar 成交
3. **移动止盈止损** — 止损只升不降 + 浮盈收紧
4. **趋势过滤** — ADX 避免震荡市入场
5. **仓位管理** — 基于 ATR 的风险预算
6. **评估指标** — CAGR / MaxDD / Sharpe / Trades / Win%
